HIYOKA AGENT (jalan di VPS)
===========================

Pasang:
   unzip connect-vps.zip && cd connect-vps && bash run.sh

run.sh otomatis: cek Node 22+, pasang unzip & pm2 kalau belum ada, tanya IP node + port bot (kalau belum diisi),
npm install, tes port, lalu jalankan agent di pm2 (nama: hiyoka-agent) + auto start saat reboot.

Agent connect KELUAR ke bot, jadi tidak ada port yang dibuka di VPS ini.

Perintah:
   bash run.sh status      lihat status + log
   bash run.sh uninstall   hentikan dan hapus dari pm2
   pm2 logs hiyoka-agent   log agent

Pengaturan di agent.conf (edit lalu: pm2 restart hiyoka-agent):
   HIYOKA_HOST / HIYOKA_PORT   alamat bot di Pterodactyl
   HIYOKA_SECRET               harus sama dengan vpsLink.secret di config.js bot
   KURO_DIR / KURO_API / KURO_PM2 / BACKUP_SCRIPT   proyek kuronime-api
   UPLOAD_ROOT                 batas folder file manager

Keamanan:
- agent.conf berisi secret. Jangan dibagikan; hapus connect-vps.zip dari VPS setelah terpasang.
- File .env, agent.conf, file/folder tersembunyi, dan folder agent/kuronime-api tidak bisa didownload,
  ditimpa, atau dihapus lewat bot. Bot hanya bisa menjalankan perintah yang ada di agent (bukan shell bebas).
